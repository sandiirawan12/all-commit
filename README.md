# All Commit

Browser tool to draft [Conventional Commits](https://www.conventionalcommits.org/) messages quickly.

## Features

- Type, scope, subject, and body fields
- Breaking-change marker
- Live preview + one-click copy
- Local draft history (saved in your browser)

## Run locally

```bash
npm start
```

Open [http://localhost:4173](http://localhost:4173).

Or open `index.html` directly in a browser.
